# Generated HTML examples

这里保存可直接用浏览器打开的生成结果，方便在未配置第三方服务时查看 Demo 效果。

- `ctrip-live-demo.html`：携程机票、列车与住宿组合报告。
- `香格里拉.html`：带来源链接的小红书旅行攻略。
- `京都.html`：带来源链接的小红书旅行攻略。
- `上海.html`：旅行攻略页面示例。
- `香格里拉-丽江-2026-10-02-2026-10-07.html`：小红书、携程和高德编排后的交互式旅行规划模板样例。

这些文件是生成时刻的静态快照，不代表实时价格、余票或最新旅行信息。新的携程单项报告默认写入 `ctrip-report.html`，新的小红书攻略写入 `<目的地>.html`。
